# 🔄 Operaciones CRUD con Python y SQLAlchemy

Implementación básica de persistencia de datos conectando Python con una base de datos relacional mediante el ORM SQLAlchemy.

* **`setup.py`:** Configuración del motor de base de datos y creación de modelos/tablas.
* **`create_users.py`:** Inserción de nuevos registros.
* **`read_users.py`:** Consultas y filtrado de registros existentes.
* **`update_users.py`:** Actualización de campos en la base de datos.
* **`delete_users.py`:** Eliminación segura de registros.
