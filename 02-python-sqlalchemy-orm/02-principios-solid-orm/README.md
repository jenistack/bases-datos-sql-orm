# 🏛️ Principios SOLID aplicados a SQLAlchemy

Ejercicios prácticos de refactorización y arquitectura limpia aplicando los 5 principios SOLID sobre modelos y operaciones de base de datos:
* **S** - Single Responsibility Principle (`SingleResponsibilityPrinciple.py`)
* **O** - Open/Closed Principle (`OpenClosedPrinciple.py`)
* **L** - Liskov Substitution Principle (`LiskovSubstitutionPrinciple.py`)
* **I** - Interface Segregation Principle (`InterfaceSegregationPrinciple.py`)
* **D** - Dependency Inversion Principle (`DependencyInversionPrinciple.py`)
