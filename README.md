# 🗄️ Bases de Datos Relacionales (SQL) y ORM con Python (SQLAlchemy)

Repositorio práctico dedicado al diseño, consulta y optimización de bases de datos relacionales en SQL, así como su integración con Python mediante el ORM **SQLAlchemy** y arquitectura **SOLID**.

## 📂 Estructura del repositorio

### 1️⃣ `01-sql-mysql/` — Lenguaje SQL Puro
* **`01-ddl-creacion-y-carga-datos.sql`:** Definición de esquemas, tablas, restricciones e inserción inicial de registros.
* **`02-consultas-y-ejercicios-base.sql`:** Consultas `SELECT`, filtros, agrupaciones y uniones (`JOIN`).
* **`03-subconsultas-y-avanzadas.sql`:** Consultas anidadas, vistas y lógica SQL avanzada.
* **`04-optimizacion-y-buenas-practicas.sql`:** Uso de índices, rendimiento de consultas y estándares de escritura.
* **`05-proyecto-final-sql.sql`:** Caso práctico integral de modelado y explotación de datos.

### 2️⃣ `02-python-sqlalchemy-orm/` — Integración Python + Bases de Datos
* **`01-crud-basico-orm/`:** Implementación de operaciones CRUD (`Create`, `Read`, `Update`, `Delete`) conectando Python con la base de datos mediante SQLAlchemy.
* **`02-principios-solid-orm/`:** Aplicación práctica de los 5 principios SOLID sobre modelos y persistencia de datos.
* **`03-sistema-facturacion-solid-orm/`:** Proyecto aplicado de gestión de pedidos, productos, aplicación de descuentos y generación automática de reportes en PDF.

## 🛠️ Tecnologías y librerías
* **SQL / MySQL**
* **Python 3**
* **SQLAlchemy** (ORM)
* **Arquitectura SOLID**
